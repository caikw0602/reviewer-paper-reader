# 创新判断与可验证研究空间

用于标准精读中的贡献与研究判断，也适用于指定查新／横向比较。以当前可取得的一手资料为依据，记录实际检索及阅读深度。

## 1. 分别判断三个问题

1. **技术差异：**相对哪一个具体方法，改变了哪项机制、目标、信息或条件？
2. **文献新颖性：**这个差异、思想或组合已有何种先例？
3. **贡献价值：**实际增加了什么知识、能力、资源或成本优势，证据有多强？

新颖性与效果可以分别成立或不足；工程组合、分析、资源和负结果也可能有价值。发表场所、名称、最高分或公式数量不替代以上判断。

## 2. 用最接近前作建立比较

先找“如果它已经做过，本文哪条创新定位会改变”的最强前例；既查同任务近邻，也查不同术语下的同机制。引用对象、最接近方法和实际实验基线分别核对。作者转述与独立回查原文明确区分。

优先比较决定问题的字段：

| 字段 | 判断内容 |
|---|---|
| 任务／目标 | 是否解决同样问题，指标与目标是否一致 |
| 信息／权限 | 标签、证据、历史、工具和环境访问条件 |
| 可改对象 | 答案、上下文、参数、记忆、工具、策略或控制程序 |
| 优化关系 | 谁提案／执行／评价；同模型不等于同信息、同权限或同框架 |
| 操作 | 如何构造候选、检索、更新、筛选、停止 |
| 验证 | 哪些信号影响决策，哪些只用于最终评价 |
| 资源 | 起点、可用数据、搜索／调参次数与实际成本 |
| 新知识 | 已证明什么，本文的剩余增量和价值证据是什么 |

只写已核内容。摘要足以支持其中明确陈述，决定差异的机制、配置或协议需回查全文／代码；缺项写具体未知。适配到共同接口的对照与原系统官方复现分开评价，跨协议分数不直接排行。

保留两条时间线：评价论文看其公开时点已有知识；为今天选题查当前解法和后续工作。精确版本、首发与修订必要时核实。查新受阻时如实限定覆盖，继续可独立完成的解释，不把检索失败当作前例不存在。

推荐定位句：

> 已查近邻X已有A；本文确认改变B；条件C下证据支持D；B的独有性或D的归因仍缺E。

当B已被前例覆盖，继续检查是否存在更窄且有价值的增量，而非直接把整篇判为无贡献。允许独有差异仍待核验。

## 3. 从疑问到研究决策

问题可来自稳定失败／异常、负结果、成立前提的边界、资源取舍、指标与任务错位，或竞争解释。先区分：

- **个人未知：**材料没读或尚不理解，先补读。
- **本文证据缺口：**先复核；一般性失效或新评估知识才可能构成贡献。
- **假设中的现象：**先观测或做诊断，尚不能预设稳定存在。
- **潜在领域问题：**已有方法在明确条件下仍有剩余困难，查当前直接解法与简单替代。

标准精读优先展开一个中心问题，不为凑数列方向。可明确没有值得推进的候选。与个人研究方向的关联要解释技术连接与新约束，单换场景或叠热门模块不足以证明价值。

每个保留候选至少包含：事实锚点与证据状态、问题价值、最近解法及阅读深度、中心假设和竞争解释、最小诊断、资源未知、继续／停止／证据不足三种结果。可用句式：

> 条件X下，机制可能因Z产生Y；若B针对Z，应观察到R，而非仅总分提高；若S成立，收缩或否定这条解释。

## 4. 先诊断现象，再验证新机制

### 第一阶段：现象与解释诊断

先确认问题存在、重要且不是简单条件变化即可解释。这一步可以不开发算法。定义样本、真值、测量、比较对象和预算：

- 指明改变因素与保持因素；同预算不代表同候选池，同样本数不代表同输入信息。
- 构造干预时，检查覆盖、冗余、辨认信息、输入几何、时序线索及成本是否同时改变，按任务选择匹配对照或因子设计。不同视角可能提供新信息；背景补位也可能造成干扰。
- 全部任务真值与当前可见证据的真值分别定义。用独立标注、可执行结果或多来源验证，模型自评不自动充当因果真值。
- 预先规定应变／不变的语义。删除证据不一定改变原任务真值，答案差不能直接贴瓶颈标签。
- 确认问题是否可识别：若全部线上可得输入相同却对应不同隐藏真值，仅凭当前输入无法保证区分。收窄假设、估计分布风险或允许追加观测，标出剩余边界。

先做能区分中心解释的最少必要设计；用于排错的小样本只验管线。正式数量与重复依效应、变异、精度与资源确定，不设通用固定次数。

### 第二阶段：机制判别

只有诊断留下实质问题，才比较所提机制、简单方案及真正近邻。除任务结果，还测特定机制预测与价值—成本取舍；严格预算匹配不可行时展示成本曲线和残留差异。oracle单列不可部署参照，简单基线使用的身份／标签／证据权限也要说明。

按任务泛化单位划分诊断／训练、选择和最终测试。标注在预定诊断或训练集用于分析学习，选择集仅用于预定选择／校准，最终测试标注用于预测后评分。最终测试后的调整需新的未见数据支持后续泛化主张；“离线”本身不排除测试泄漏。

开发前精读决定候选差异的直接近邻；形成新颖性结论前补足查新。初筛、全文机制比较、实验验证是不同成熟阶段。

## 5. 让结果改变下一步

- **继续：**现象可靠、简单解释不足，机制特定预测得到支持，且体现有意义的价值。
- **收缩／停止：**关键现象被可靠证据否定，直接前作已解决同目标，或在足够精度下简单方案达到相当价值而复杂机制代价不合算。
- **证据不足：**样本、测量或实现不足以判断，具体说明下一项最有判别力的证据。

阈值依据任务价值与测量能力确定，没有依据时保留待定。不编造成功概率、预期提升或录用前景；没有显著差异不当等效。诊断、严谨负结果与放弃重复方向也可以是有用产出。
