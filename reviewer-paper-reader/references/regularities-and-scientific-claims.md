# 规律与科学认识

用于回答“这篇论文让我们对什么有了新认识”。沿着科学问题寻找关系及边界，再解释作者如何研究或利用它；不把所有论文强写成发现了普遍定律。

## 1. 先分清四件事

| 层次 | 要讲清什么 |
|---|---|
| 科学问题 | 对象为何如此、何时成立、受什么限制；工程工作也可问哪些能力在给定条件下可实现 |
| 关系与解释 | 哪些因素、行为或结果存在何种联系；作者用什么解释这项联系 |
| 研究／解决方法 | 如何发现、测量、推导、检验这项关系，或利用已有认识解决问题 |
| 技术路线 | 方法怎样落实为数据、模型、算法、工具、执行步骤和测量协议 |

方法可以用于研究规律，也可以贡献实用能力。有效的方法不必同时提出新规律；给出公式、提高总分、设定接受阈值或展示运行轨迹，都不自动构成发现规律。区分本文**新建立的认识、借用的已有认识、尚待检验的解释**；各自与近邻比较。

## 2. 提炼一至两项最重要的认识

优先用一段自然语言说明；复杂证据才用表格，不给每项普通结果填一套表。

经验关系可写为：在对象S和条件C下，改变X时，Y呈现关系R；实际保持A，仍可能混入B。标出：

- 对象与单位：哪类模型、样本、环境、算法或系统；题、视频、训练运行等观测单位。
- 变量与测量：X、Y怎样操作和计量；实际控制、共同变化及代理指标。
- 关系与范围：趋势、取舍、分段、阈值或定量形式；测过哪些范围，哪些是外推。
- 来源与身份：原文位置；是作者结论、本次综合推断，还是教学说明。
- 反例与不确定性：退化子群、失败区间、重复性、测量误差和未测条件。

按论文类型选表达，不强套X→Y：理论工作写“假设→命题→证明适用范围”，反例检验假设与推理；资源工作先说明新增可观测／可评估能力，未做分析就不声称发现行为规律；系统工作允许结论是“在此协议下实现了某种能力”。

## 3. 校准证据能回答哪一层问题

分别判断，不能由低层证据自动跳到更宽结论：

| 本文主张 | 检查重点 |
|---|---|
| 观察到现象／关系 | 比较与测量是否支持；不同任务、子群、种子是否一致，例外是什么 |
| 提出原因解释 | 只是与轨迹一致，还是能区分竞争解释；跨模型架构比较可能同时改变数据、训练等条件 |
| 证实某项干预有效 | 干预与对照实际同时改变了什么；局部干预效果不等于内部机制已被证实 |
| 具有预测性或可迁移性 | 是否预测未参与拟合／选择的数据、范围、任务或模型；预测成功的条件与误差 |
| 得出理论结论 | 假设、量词、证明与结论是否匹配；经验符合不替代证明 |

观察、解释、干预效果、外推与证明是不同主张，并非所有论文都需要做到每一项。不要把模型行为类比人类记忆等现象写成同因果机制。

定量拟合还需核对：变量定义与单位、拟合样本和区间、其余瓶颈／饱和条件、公式中的近似或不可约项、残差／不确定性及未报告项。区分实测点、拟合曲线、校正或模拟后的量、由经验模型推导的资源建议；对数坐标接近直线不等于理论定律。少数规模点的关系不能无条件迁移到新数据、新模型或端到端任务效用。

遇到冲突先保留条件：同一系统总分上升与子能力退步可以同时成立；两套分类不一定等价；迭代时题集改变后，原始准确率不能直接作能力进步曲线。不凭单例或单方向迁移声称普遍性。

## 4. 用边界寻找值得验证的问题

从一项已有认识出发，只保留最有价值的一条延伸链：

> 已知关系 → 未测边界／反例／竞争解释 → 可区分的预测 → 最小诊断 → 新增认识 → 继续或停止。

先问“换条件后关系是否仍在”“哪个解释产生不同预测”，再决定是否需要新方法；不默认从缺失实验跳到算法创新。预测写清比较、方向或关系及可否定结果；没有依据时不编数字门槛。诊断阴性、发现不适用边界或否定流行解释，也可能增加知识。

原论文贡献按其公开时点判断；今天的资源配置或选题需要查直接后续工作。发现后来已有解法时，转为理解差异／复核边界，不能把历史问题包装成当前空白。当前查新不足就明确“诊断候选，尚未确认新颖性”。具体权限、预算、划分及决策按 [创新与研究](novelty-and-research.md) 执行。
